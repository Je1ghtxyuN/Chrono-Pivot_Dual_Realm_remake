# 第三关声学改造

工程：ChronoPivot_ReportVR。三步流程保持为敲钟、寻找共振、拍频调谐。

- 木槌和悬挂钟替代试验方块；只认可拿住指定木槌的正向有效撞击，轻放、擦碰、投掷及其他物件不计。敲击间隔至少0.25秒，避免一次碰撞抖动重复计数；松手后才推进任务。
- 敲钟只播放已有音库中的衰减钟声，移除同时叠加的连续纯音。余振指示随时间衰减。
- 共振实验使用固有频率220Hz、阻尼比0.04；曲线和读数来自同一受迫振动公式，峰值归一化。阻尼共振峰约219.65Hz，达到94%后松手保持1秒即可通过。
- 拍频实验用220Hz参考音与可调纯音混合。粗调210～230Hz，微调±1Hz；读数、音频和通关检查使用两者之和。光柱由音频回调中的真实相位包络控制，不再借用共振摆动。
- 持续音只在当前任务或握住该实验旋钮时播放，降低互相干扰。拍频≤0.3Hz，松开两个旋钮并保持1.5秒才通过。

VR用握把拿取、转手调节旋钮；桌面按住左键/E拿取、拖鼠标调节。敲钟应拿住钟槌撞击，不必抛掷。R重置任务、器材与声音相位。通关方式见逐关解谜攻略第三节。

这是声学示教模型：钟声使用合成音库，未根据钟体几何计算音高；共振采用线性稳态模型，实体摆片为慢速示意；拍频在单个声源位置混合两路纯音，未解算空间声场。同频时合成音的强度也取决于相位，因此通关按频差与松手稳定时间判断。

菜单 `Report VR / Acoustics / Upgrade Third Level` 更新第三关。自然实验重新生成时也会应用此改造；手工编辑 Acoustic feedback 与 Acoustic bell support 子对象前先备份，它们会被重建。

验证入口：`AcousticExperienceCheck.VerifyAndPreview` 检查音库、单钟声路径、共振响应、粗调微调、音频样本和包络；`NaturalAllPlayCheck.AcousticOnly` 检查实际虚拟XR碰撞、抓取、错误条件、松手通关与重置。截图和结果在 `Documentation/AcousticReview`。真实头显的听感、抓取手感和帧率仍需实机检查。
