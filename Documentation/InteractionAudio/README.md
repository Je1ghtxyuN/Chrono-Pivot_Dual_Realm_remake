# 交互音效

交互音效包含 40 个原创程序合成 WAV（单声道、44.1kHz、16bit），用于现有 15 个关卡。素材以木石碰撞、铜器、机械声、水流和简短五声音阶组成；未使用外部素材或真实录音。背景音乐已移除，游戏仅保留实验、交互与轻脚步音效。

## 调整与试听

2026-10-07：石地、木桥和雪地脚步均改为轻柔沙沙摩擦声，去掉撞击正弦音，主要保留70–600Hz的带限噪声，使用平滑起落包络。素材RMS为0.03，默认脚步组件音量0.4、音效库条目0.1，总库音量0.8时音源实际音量0.032；在距离衰减前，实测峰值比旧脚步降低约25–27dB。行走距离、地面分类和暂停判定保留。

仅重生成脚步：`python Documentation/InteractionAudio/generate_footsteps.py`；数值检查见 `footsteps-waveform.txt`。旧的全库生成脚本会恢复旧脚步，若使用它需随后运行这个脚步脚本并恢复上述库音量。可在[轻脚步试听页](../MusicReview/index.html)试听。

- 在 Unity 中选择 `Assets/ReportVR/Resources/InteractionSoundBank.asset`：可调整总音量、各声音的音量/音高范围/最小触发间隔/优先级、同时播放上限和距离衰减。
- 游戏设置中的音量滑块继续控制 `AudioListener.volume`，同时影响音效和声学实验。
- 运行时自动给抓取物、骨牌、玩家与关卡挂接声音组件，现有场景无需重建。
- 若需保存单个物件的参数，在编辑模式为该物件添加 `ReportObjectAudio`：可指定木/石/金属/雪/玻璃，调整音量、碰撞速度门槛、满音量速度、碰撞间隔、机关运动门槛和滚动声音。自动装配会保留已有组件的设置。
- 可为关卡添加 `ReportExperimentAudio` 保存实验机关音量，为玩家添加 `ReportFootstepAudio` 保存步幅与脚步音量。自动装配会保留这些组件。
- `ReportAcousticMeasure` 的 `experimentVolume`、`strikeVolume` 分别控制物理合成音和敲钟声；原来的驱动频率、共振和拍频计算保留。
- 打开同目录 `index.html` 可逐项试听原始素材。游戏内的实际响度会受音量设置、作用力度与听者距离影响。

## 触发对应

| 操作 | 声音依据 |
|---|---|
| 抓取、放下、抛出 | XRI 真实选择/退出选择、最终刚体释放速度 |
| 木石、铜器、雪、玻璃碰撞 | 真实碰撞相对速度决定响度，连续碰撞节流 |
| 旋轮、转动太阳/镜子/指南器、滑杆 | 选中且数值实际变化后发声，程序复位不发棘轮声 |
| 小球滚动、骨牌倒下 | 地面接触及速度驱动滚动循环，骨牌使用短木质碰撞 |
| 投掷命中、滚入接收器 | 实际落点/到达判定认可后发声，重复命中不刷响 |
| 归位、船上装载、雪块结合 | 实际冻结归位、首次装载、接触生成物理关节 |
| 钟槌、共振、拍频 | 认可的钟槌撞击响钟，声学频率继续由物理实验生成 |
| 水闸、管道 | 阀门开度与泄漏/密封状态调节水流循环 |
| 电磁锁 | 有铁芯且有电流时低嗡鸣，实际吸合/断开时响机械锁 |
| 融雪、隔热 | 样品位于暖区且尚未融尽时循环，隔热降低响度；融化进度产生稀疏水滴 |
| 反射光路 | 光路从未接通变为接通时提示 |
| 关卡进度与出口 | 非最后一步短提示；最终完成与解锁，门移动时机械循环 |
| UI、重置、切关 | 桌面/VR 公用指针事件、按钮、滑块、菜单开合；重置与切关先清除世界声音 |
| 移动脚步 | 实际水平移动距离，地面检测区分石地、木桥与雪地 |

世界音效采用 3D 距离衰减；菜单和最终通关提示音采用 2D。暂停时抑制世界声音，菜单与通关提示仍可发声，通关菜单不会打断完成提示。声音对象的循环随物件销毁，切关时清理已销毁引用。
