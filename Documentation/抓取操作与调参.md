# 抓取操作与调参

## 第一关如何验证

打开 `Assets/ReportScenesLowPoly/Scenes/Fig_2_01_Introduction.unity`，或启动工程目录中的运行脚本。

三种材料的 `材料样品` 子物体可抓取。`底座` 保持固定。

- VR：手靠近样品，按住该手的握把键；也可将手柄射线对准样品后按住握把键。移动手柄会带动物件，松开后落下。正确物件在同名槽位附近松手会固定，可再次拿起。扳机切关仅在通关后或启用调试导航时可用。
- 桌面：使用 `Launch_Desktop.cmd`。先点击画面空白处锁定鼠标，再将准星对准样品，按住左键或 E。物件拿到相机前方，随视角和 WASD 移动；松开后落下。Esc 释放鼠标时也释放物件。
- R 或 VR 左手菜单键：重置任务和物件，包括正在拿住的物件。重置后先松开抓取键，再次按下才能重新抓取。

任务按钮仍可用左键/E或右手握把操作。抓住物件期间不会同时操作任务按钮。

## 已接入的便携物件

- 第一关：3 个材料样品。
- 浮力水渠、园林水渠：各 3 个工作台配重。
- 编钟关：钟槌、铜锭。
- 创意工坊：30 个架上模块。
- 冰雪资产展示：3 个对比雪球。

另有液压关备用密封圈，共45个物件。建筑、底座、工作台和演示机构保持固定。水渠任务要求木40kg和石60kg在对应槽位中，铜配重不能堆在槽位附近；归位验证后显示100kg对应的浮力演示。kg标签是解谜载荷数据，抓取用Rigidbody仍以1kg保证操作稳定；演示没有实时浮力求解。

## Inspector 参数

左右手柄和 `VR Main Camera` 上的 `ReportGrabInteractor`：

- Near Radius：手部近距离抓取范围，默认 0.16 米；桌面不使用。
- Ray Distance：射线抓取上限，默认 4 米，实体模型会遮挡射线。
- Desktop Hold Distance：桌面拿住物件时距相机的距离，默认 1.2 米。
- Grab Input：左/右握把输入，包含 Grip Pressed 和模拟 Grip 达到 0.6 的绑定。
- Desktop Only：仅相机抓取器勾选，左右手柄不勾选。

样品上的 `ReportGrabbable` 使用 XR Interaction Toolkit 的原生抓取设置，可以调整附着缓动、运动方式、抛掷速度倍率等。Inspector 的“释放速度”区域可调整最大释放速度和角速度。桌面默认平稳放下，勾选“桌面允许抛掷”后才从相机移动估算抛掷；VR保留抛掷，默认释放速度上限为 8 米/秒。`Rigidbody` 可以调整质量、重力和阻力；动态网格碰撞体必须保持 Convex。每件物体同时只能被一只手拿住。

退出播放前的试调值不会自动保存，正式参数请在停止播放后设置并保存场景。

## 2026-10-02自然互动更新

桌面拿住普通道具时按住右键或F蓄力，松开右键/F抛出。机关抓住后拖鼠标调参数，不能抛出。VR继续以挥手后松握把释放刚体。按住抓取键抛出后会暂时锁定重新抓取，先松抓取键再拿取。
