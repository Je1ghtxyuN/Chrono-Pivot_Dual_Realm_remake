# 关卡编辑与调参

## 打开第一关

在正式工程 `ChronoPivot_ReportVR` 打开 `Assets/ReportScenesLowPoly/Scenes/Fig_2_01_Introduction.unity`。后续关卡按 Build Settings 中的顺序排列；逐关处理记录见 `LevelReview/逐关编辑性检查.txt`（记录中的序号从 0 开始）。

## 人物与操作

选中 Hierarchy 中的 `Report VR Origin`，在 `DesktopPlayer` 的中文 Inspector 调整：

- WASD 移动速度：米/秒，0 可停止行走。
- 鼠标灵敏度：度/像素；俯仰限制、反转垂直方向。
- 桌面视角高度、胶囊高度和中心、重力倍率、最大下落速度、贴地速度。
- 操作提示和准星开关。
- 同一区域可直接调整 VR 行走速度、每次转向角度和转向间隔。这些值写入原有 VR Provider；当前使用分段转向，转向节奏由角度和间隔控制。

胶囊半径、台阶高度和最大坡度在 `CharacterController` 中调整。改变身高或胶囊后应重新检查路线。

主角色 `Ch46Player.prefab` 使用 `LowPolyPlayerAvatar.skinnedRig` 驱动 FBX 骨骼，可调整桌面手部位置、跟踪高度范围与步态。手臂长度读取骨骼，肩宽和手臂长度字段仅适用于旧自建角色。头部偏移参与启动身高校准；第一人称可见性在开始播放时应用。

播放时可以试调数值；退出 Play 会恢复原值。请在停止播放后设置并保存正式参数。

桌面使用 `Launch_Desktop.cmd`，WASD 行走、鼠标观察、左键或 E 互动、R 重置、Esc 释放鼠标。VR 使用 `Launch_VR.cmd` 并将 SteamVR 设为活动 OpenXR runtime。

## 文字朝向

选中文字物体，在 `ReportTextFacing` 中设置：

- 固定在世界/告示板上：使用场景中的旋转，不随玩家转头。所有关卡的告示板默认采用此模式。告示板与文字一起编辑时，保持父子关系。
- 朝向玩家：用于悬浮提示，指定 Viewer；Yaw Only 可限制为仅绕竖直轴转动。
- 跟随父物体：用于手腕说明等，随手部姿态变化。

文字材质保留深度测试，文字应放在牌面前方，避免穿透或与牌面重叠。中文字体在播放时初始化；普通编辑模式下的文字材质预览可能不完整。

## 模型分离

第一关 `HubMaterialCube_0` 至 `HubMaterialCube_2` 各含 `材料样品` 和 `底座`，可分别移动、缩放和调整材质，两者保留碰撞体。样品已贴合底座顶面。

后续关卡按用途拆分了工作台和器材、配重与船体、编钟和钟架、仪器与底座、置物架与模块等。拆分网格位于 `Assets/ReportVR/EditableModels`，原始自建模型和材质资产保留。

闸板与机械摆恢复完整活动网格，并重新绑定 `DemoStation.movingPart`。活动件继续关闭碰撞，避免演示动画挡住玩家；它们目前属于演示动作。

## 任务与反馈

- `DemoInteractor`：交互距离、有效/空白目标射线颜色，以及相机、右手和输入引用。
- `DemoLevel`：任务顺序、出生点和朝向、路线、文字换行长度、出口门移动速度。
- `DemoStation`：动作类型、目标值、每次操作采用的 Values、活动部件、位移、观察位置和三种状态颜色。不同动作的 Values 单位不同，请参考字段说明和现有任务配置。
- `DemoExit`：Auto Advance 控制完成后经过出口是否自动切关。

后续关卡的部分物理和动画常量仍在 `DemoStation`/`DemoPhysics` 中；本轮没有把所有动作常量改成 Inspector 字段。逐关深入完善时继续处理这些参数及实际玩法。

## 检查范围

本轮检查模型可编辑性、文字朝向、15 个场景路线、任务完成和重置，具体结果见 `Verification` 文件夹。路线检查包括地面、坡度、胶囊净空和 CharacterController 行走。虚拟头显/控制器测试用于验证脚本及引用，不等同于真实头显、SteamVR 串流和双眼画面的实测。

不要运行旧的全量场景生成菜单来保留这些修改；`PolishReportLevels.Apply` 会从旧备份重建场景。
