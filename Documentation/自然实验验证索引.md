# 自然实验验证索引

当前玩法为15关、45项模型互动实验，所有关卡节点为Physical模式，无A/B/C答案按钮。编辑器路线检查和运行实验测试分别记录，不用预设答案来伪造完成。

- `level-routes.txt`：15场景路线采样、坡度、胶囊净空、实际CharacterController行走和实验引用。
- `natural-first-playtest.txt`：模拟VR抓取三材料、装杯、拉杆发射、三质量真实落点、太阳轨道拖动、实体出口切关。
- `natural-all-playtest.txt`：其余14关实际抓取、机关拖动、刚体撞击、落点命中、反射、沉浮、周期/频率、液压、稳定结构、重置、出口门。
- `grab-playtest.txt`/抓取测试生成文件：键鼠蓄力抛出与防止立即重抓、VR双手抓取与重置。
- `desktop-playtest.txt`/桌面测试生成文件：WASD/鼠标/场景调试输入回归。
- `windows-build.txt`：当前Windows构建结果。
- `asset-migration.txt`：614个原自建资源、15关、23原报告照片、GUID与OpenXR插件检查。
- `RemainingReview/physics.txt`：第五至十五关相关的15项行为回归；该目录另含27张实验近景和最终运行包一致性证据。详情见[第五至十五关体验改造](第五至十五关体验改造.md)。

`Documentation/LevelReview/Atmosphere`包含15关的出生视图、概览和实验近景，共45图。实验特写拍摄时临时隐藏周边任务牌，拍完恢复；出生视图与概览保留完整布局。自建装饰无碰撞，不改变实验灯光和人物。

旧名称为puzzle-*、旧45选择题等测试文件是历史记录，不代表当前自然实验验证。当前运行测试使用虚拟控制器，自动球投掷标定初速后真实释放与碰撞；桌面抛掷输入另有回归测试。尚未真实头显/SteamVR串流实测。
