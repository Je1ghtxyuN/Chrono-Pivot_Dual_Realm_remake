# 投掷重试与抓取优化 · 2026-10-08

本轮解决两处操作阻碍：桌面抓取物件时突然拉近，以及投掷失误后必须走远找物件或重置整关。

## 使用方式

- 桌面抓取普通物件时，在 0.45～2.5 米的操作范围内保留原有距离，之后仍可用滚轮拉近、推远。更远的物件拉到最远操作距离；机关和 VR 跟手操作保持原有方式。
- 当前步骤为投掷实验时，打开“当前任务”，点击“取回未命中物件”。桌面可按 Tab 进入，VR 用菜单切到当前任务并用扳机点击。
- 取回仅恢复当前投掷目标接受且尚未命中的物件，不清空已完成步骤、已命中次数或不同材料计数；已经投中的材料留在原处，其他实验器材不动。
- 取回后恢复正常操作，可以继续真实投掷。取回不会计为命中，整关重置仍是独立操作。
- 非投掷步骤和已完成关卡不显示取回按钮。
