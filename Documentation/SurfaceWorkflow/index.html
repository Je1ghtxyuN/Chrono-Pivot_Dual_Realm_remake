处理方式

  • 焊接位置、法线和顶点色一致的顶点；清除零面积面、重复面及未使用顶点。保留硬边法线、轮廓、材质槽和资产 GUID。
  • UV0 用于材质；UV1（Unity 的 mesh.uv2）保留独立图集，可供后续光照烘焙使用。折叠的细小面拆为独立 UV 岛。
  • 256 / 512 / 1024 分辨率按面数选择；完整延展 UV 岛边缘，使用 mipmap、三线性过滤和高质量压缩。
  • 每个顶点发射 12 条余弦半球射线计算局部 AO；材质 AO 强度默认 0.65，可在 Inspector 调整。
  • 人物的原始骨骼、权重、UV 和贴图保留；透明水体与已有贴图材质沿用原设置。
