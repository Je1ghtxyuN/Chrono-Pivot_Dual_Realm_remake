# 关卡切换粒子过渡

菜单选关、通关后的“下一关”、实体出口以及允许的快捷切关，统一使用原有加载权限入口。

1. 确认切换后，40 个青色/金色小粒子从视野周边聚拢，同时在约 0.32 秒内淡出。
2. 遮罩覆盖后加载新场景；等待实际加载完成，不用粒子假装加载进度。
3. 新关卡出现时，粒子向外散开，在约 0.38 秒内淡入并退去。结束后清空粒子和遮罩，恢复操作。

特效使用非缩放时间，菜单暂停不会卡住过渡。切换期间锁定输入并拒绝重复请求；未解锁/非法选关不触发特效。一个持久组件供全部关卡复用，不修改各关卡物理参数或任务。

粒子上限 64，不使用碰撞、灯光或阴影。动画是场景切换的符号反馈，与实验中的物理粒子区分；不旋转相机，不增加全场常驻粒子或数字面板。使用原有切关声音。

验证范围：实际菜单选关按钮、暂停时淡出、重复点击、真实场景加载、清理与操作恢复、通关出口真实触发，另复测现有桌面/虚拟 VR 菜单操作。头显帧率和佩戴舒适度需在实际设备上确认。
