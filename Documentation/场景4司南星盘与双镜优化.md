# 场景 4：司南、星盘与两次反射

## 场景变化

- 司南替换为宽凹勺头、细长柄的勺形模型，勺柄朝南；握持勺子拨开并松手后，仍按原来的磁力矩与阻尼回南。旧装饰勺模型隐藏，避免两个司南混淆。
- 转动星盘会同时旋转程序星空、云层图案及北斗七星模型，固定方位参照不动。背景星空与北斗使用同一旋转，松手后保留当前角度，重置恢复原位。
- 光源先到一号铜镜，再到二号铜镜，最后到接收器。两面镜都可拿住调整，金色光束显示三段实际光路，青色线表示各镜法线。接收器面对第二面镜，命中后亮绿。
- 两面镜都松手、光路连续接通并保持稳定后，才完成镜面实验。挡住任一光路、转错二号镜或绕过二号镜都不计通过。
- 隐藏挡住新装置的旧装饰铜盘，并更新了入关说明、任务提示和完成后的下一步引导。

星空旋转是天球运动示教，未增加真实天文授时计算。其他关卡保留原有单镜实验；此前的取回投掷物、抓取距离、自然开门、切关粒子及无 BGM 设置保留。
