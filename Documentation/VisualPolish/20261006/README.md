# 场景视觉优化 · 2026-10-06

本轮更新 NewVersion 的 15 个场景光照和 1619 个材质实例，保持低多边形轮廓、原配色、网格、UV、路线及互动设置。前后效果见本目录的 index.html。

## 表面细节

- 木材：细木纹与轻微起伏。
- 石材：柔和颗粒及粗糙度变化。
- 墙面：浅色灰泥的细微起伏。
- 屋瓦：瓦缝、瓦面弧度与较柔和的高光。
- 金属：拉丝细纹与粗糙度变化，保留已有金属度。
- 积雪：细小晶粒和柔和色差。
- 地表：不规则的浅色变化，避免大片地面过于平坦。

七类表面共享 14 张原创 1024×1024 贴图，PNG 合计约 7.3 MB。纹理由周期数学图案生成；采用 Mipmap、Trilinear、8 级各向异性过滤及高质量压缩。图案按物体局部坐标投影，抓取和移动物体时不会相对表面滑动。原烘焙贴图、AO、交互颜色和硬边法线仍保留。

## 继续调整

选择材质，在 Inspector 调整“精细表面”“每米细节重复次数”“细节颜色强度”“细节法线强度”和“粗糙度变化强度”。小型物件不必放大纹理强度；近景细节应与清晰的大色块兼容。

场景主光阴影分辨率改为 High，阴影强度为 0.65，减少偏移以改善接触处的悬浮感；环境反光略偏冷。Unity 菜单“Chrono Pivot / 视觉优化”提供重新应用和拍摄入口。

## 验证与边界

Unity 材质与着色器检查通过；五个代表场景拍摄了同机位全景和近景。1365 个网格资产的文件哈希保持一致；14 个已备份场景的层级、物理与脚本组件一致，15 个场景均经过编辑器内的修改前后组件状态检查。结果记录于 verification.json。

这轮未改报告正文、未重建 Windows 可执行程序。运行 Unity 场景可使用新材质；Builds 中已有程序仍是此前的版本。头显帧率和实际 SteamVR 串流表现需要实机测量。
