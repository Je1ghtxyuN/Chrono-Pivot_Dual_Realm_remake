本包仅保留选中的3B LoRA权重与分词器、训练配置和指标、RAG知识卡、运行代码、网页、Unity组件及轻量测试。模型权重未修改。
本地已补充下载并校验的 Qwen2.5-3B-Instruct 基础权重；不含服务器日志、个人SSH配置、账号、密钥、内部研究记录或报告截图。

Qwen/Qwen2.5-3B-Instruct 用于加载3B适配器，权重位于导师根目录的 models/Qwen2.5-3B-Instruct。基础模型配置已指向该本地权重；本机 NF4 四位量化 HTTP 服务通过启动导师.cmd 运行。
详细步骤见队友部署说明.md。

本机服务使用独立 .venv 和 CUDA；Unity通过HTTP调用后端。原适配器加载检查脚本仍仅用于Slurm环境。真实文字联调已记录，回答存在物理错误和提示等级不足，不能视为教学质量验收通过。
