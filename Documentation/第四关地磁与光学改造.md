# 第四关：地磁与光学

本轮按顺序调整第四关的三个实验。沿用现有场景风格和握把操作，通关根据实际测量结果自动推进。

## 通关操作

1. 司南：握住勺柄，拨离南向至少20°，松手观察回摆；南向偏差≤5°并稳定1秒后通过。只轻微拨动不计。方位盘已校准到场景世界方向，约定+Z为北、−Z为南。
2. 观测环：握住圆环沿圆周拖动，把红色照准线指向金色星标；平面照准偏差≤3°，松手稳定1秒。判断实际星标方向，不只判断固定45°数值。
3. 铜镜：握住边框转动，让金色入射光到达镜面，再反射进入接收器。蓝色线表示法线，面板显示相对法线的入射角和反射角。接收器亮绿后松手稳定1秒。可绕到侧面查看光路；任何一段被实体挡住都无法通过。

## 实现范围

- 司南采用正弦磁恢复力矩和阻尼的单自由度模型，允许回摆后衰减；不读取头显磁力计，不模拟真实勺体接触与地磁场分布。
- 观测环是平面照准示教，不模拟完整天体坐标。星标微小深度偏移投影到观测环平面；抓取时测量平面仍固定在实验台。
- 铜镜采用单束几何光学，忽略衍射、散射和能量损耗。入射段和反射段都检测实体遮挡。共享镜面逻辑同时影响第九、十关和末尾园林；共享司南逻辑同时影响第十四关。
- 提升读数对比度，将浮空任务状态移到对应实验台上方；光路抬高，避免和背景金色栏杆重叠。
