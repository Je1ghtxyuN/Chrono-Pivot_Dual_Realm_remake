# 第二关简易装载

小实验台位于大水槽左侧岸边，与大水槽分开摆放。台内是带尖船头、木甲板、船舷和尾舵的木船模型。面对配重托盘，将木块拿到小船白色边框上方，松开握把。整块船面都能接收材料，无须寻找隐藏槽位。材料自动摆好、船身随载荷下沉即为装载成功。

1. 装木块：总重30kg，白色25%水线与水面齐平。
2. 再装石块：总重60kg，金色50%水线与水面齐平。
3. 转闸轮至全开并松手：让船通过闸口。

铜块是可选的过载实验。再加铜块后总重150kg，船沉底且不能通航；抓起铜块带离船面，放回岸边托盘，船恢复浮起。

船面显示亮色边框与“装船区”提示，侧边仅显示简短的物理现象和下一步动作，留出观察后方大船的视线；重量和水线百分比不再持续展示。托盘、船底以及仍拿在手中的材料不会计入载重。松手后的自动归位是辅助装载，浮力仍按实际计入的质量计算。

后方大船同步显示木、石、铜配重以及下沉、过载和卸载上浮；转动闸轮时，大闸板同步抬升，安全通航时大船同步驶向闸口。大小模型共用小船的实验状态。浮力沿用封闭浮箱的教学计算，大模型以放大的位移展示结果，不单独计算第二套物理。

修改仅启用于第二关。编辑器菜单 `Report VR / Water / Simplify Second Level Loading` 更新该关场景；重新生成水体或自然实验时会自动保留这项配置。

验证记录见 `CargoReview/loading.txt`、`CargoReview/boat-display.txt` 与 `CargoReview/input-playtest.txt`；离线检查不能替代头显实际手感验证。

本次验证运行包：VR 使用 `Builds/Windows_CargoLoading/ChronoPivot_ReportVR.exe`；桌面使用 `Builds/WindowsDesktop_CargoLoading/启动桌面验证版.cmd`。预览见 `CargoReview/loading.png`。
