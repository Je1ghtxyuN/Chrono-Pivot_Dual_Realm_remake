# 自然物理实验：操作与编辑

## 玩家操作

每关三项实验按顺序完成。告示板显示目标和物理关系，器材旁显示实测或计算读数。直接拿取、插入、转动、拖动、敲击、滚动或抛掷模型，条件达成并稳定后自动推进。状态灯仅反映进度；提示按钮可显示操作引导。

- VR：握把拿取，松开放下；挥动手后松握把抛掷。机关沿滑轨拖动或转动手腕；偏心握点可沿圆弧拖动。
- 桌面：WASD移动，鼠标转向；点击画面锁定鼠标，Esc释放。按住左键或E拿取。拿住机关时拖动鼠标调节；拿住普通道具时按住右键或F蓄力，松开右键/F抛出。抛出后先松抓取键再拿下一件。
- 材料归位、铁芯、密封圈、模块连接使用明确的装配槽，松手后固定；再次抓取可取出。
- 船舱配重跟随船运动，拿出即减载。雪人和桥梁支撑使用真实重力与碰撞，必须松手并等待稳定。压实雪层以平面接触叠放，接触后形成可断裂FixedJoint近似黏结，拿起时解除；位置不会自动吸附。
- 球必须从实验台附近真实抛出，走到靶区放入不计命中。轨迹仅记录已发生的飞行，落地后短暂保留。
- R或左菜单键重置道具、测量、任务、出口门和出生位置。重置后先松抓取键。
- 三项完成后等待门打开，沿步道走入出口。未通关不能用场景菜单或扳机跳关；调试导航可在Inspector开启。

第一关使用标定发射器：一件材料入杯→拉杆拉到底→松手。初速和仰角保持相同，轨迹由刚体重力产生。三种质量都必须真实命中，然后拖动太阳到东方，看日晷影子向西。

完整操作见 `逐关解谜攻略.md`。

## Inspector可调整项

- `ReportGrabInteractor`：桌面抓取距离、抛掷最小/最大速度、蓄力时间。
- `ReportGrabbable`：释放速度与角速度上限、刚体质量；`ReportThrowTrack`：轨迹颜色、保留时间、最小记录速度。
- `ReportMechanismHandle`：旋转/滑动模式、轴、参数范围、初值、角度/行程范围、VR映射尺度、鼠标灵敏度、读数单位。360°轨道应设VR角度映射为360°。
- `ReportLearningTask`：测量源、达标范围、当前任务开始后需要的操作次数、是否必须松手、稳定时长。
- `ReportPuzzle`：目标、物理关系、提示、实际装配物件与槽位。当前关卡使用Physical模式，所有Choices为空。
- 水渠：船体质量、水密度、排水体积、船深、沉浮速度、通航位移。配重质量在各自Rigidbody上。
- 声学：固有频率、阻尼、有效敲击速度。共振振幅采用解析公式，实际声音由合成音输出；振幅标记刻意慢速展示。
- 光学：实际可转镜面、接收器Collider、射线长度。光线由镜面法线实时反射与Raycast检测。
- 电磁：匝数、线圈长度、安全电流上限、铁芯位置；磁锁要求铁芯安装且电流安全。
- 液压：输入/输出面积、输入力、载荷力。满足力比和体积/行程关系；卸压、密封、开阀、压活塞按顺序。
- 单摆：阻尼、摆长范围、角度范围；周期从真实数值积分的过零时刻记录。LC：电感、电容范围。
- 热学：暖区温度、传热系数、冰样质量、潜热、隔热系数。展示为缩时模型，初始冰温0°C。
- `DemoLevel`：出口位移/速度、路线、任务文字；人物速度与转向速度继续在`DesktopPlayer`和VR移动组件中调整。
- 天空与装饰：`Assets/ReportVR/Atmosphere/Profiles`中的Garden/Twilight/Snow/Laboratory四份Profile。调节天空配色、云量、星光、远景日晷尺寸与位置、山峦数量和装饰配色后，运行视觉氛围“应用全部15关”。

固定告示板和读数为`WorldFixed`，物件标记随父物件旋转。中文使用Windows微软雅黑/黑体。

`Report VR/Natural Learning/Configure All Levels`会重建自然实验台、任务和槽位，覆盖这些生成对象的手动修改。日常调参直接保存场景，无需重建。旧选择题配置及测试仅留作历史源码，不能用于验证当前实验玩法。

## 物理范围与验证

真实刚体：自由抛射、落点碰撞、敲钟接触、骨牌连锁、滚球、桥梁支撑叠放。压实雪层使用接触后可断裂连接的黏结近似。
简化模型：箱形船准静态阿基米德浮力；理想长螺线管磁场；不可压液体准静态液压；重力单摆数值积分；受迫振动幅度与拍频；潜热融化与隔热。水平日晷实验用于影向比较，未实现精确纬度校准的天文读时。远景巨型日晷为主题装饰。

验证资料位于`Documentation/Verification`，自然实验使用`NaturalFirstPlayCheck`与`NaturalAllPlayCheck`，抓取/桌面使用原输入回归。模拟控制器验证不能替代真实头显、SteamVR串流与舒适度实测。
