# 晷枢双界 · 游戏界面

界面已接入 NewVersion 的全部 15 个关卡，使用青绿、象牙白和黄铜配色，配合由 UI 网格绘制的日晷标记。

## 界面

- 探索首页：开始 / 返回探索、当前关卡与任务状态。
- 当前任务：读取关卡的真实目标、线索、三个步骤和实验测量；提示按钮调用现有谜题的提示，不能代替物理操作通关。
- 关卡地图：15 个关卡，按进度解锁；可重玩已解锁关卡。现有 `allowDebugNavigation` 可用于开发时自由选择。
- 设置：音量、行走速度、分段转向角度、鼠标灵敏度、任务面板显示。
- 操作指南：根据当前控制模式显示键鼠或 VR 操作。
- 通关反馈：全部目标完成后自动出现，可继续探索或前往下一关。
- 重置 / 退出确认：避免误操作清空进度或退出。
- 载入状态：显示 `SceneManager` 异步载入进度，进入下一场景后恢复游戏。
- 桌面 HUD：当前任务、准星、拿取 / 机关 / 抛掷提示。
- VR HUD：左手腕任务面板，以及视线下方的交互提示。

## 操作

桌面：`Esc` 打开 / 关闭菜单，`Tab` 打开任务；鼠标点击按钮、拖动滑条。返回探索后自动恢复鼠标观察。

VR：右 B / 右菜单键打开 / 关闭菜单。左右手柄射线指向按钮，按下并松开扳机点击；握住扳机可拖动滑条。左 B / 菜单键保留为关卡重置输入。握把仍用于场景抓取。

菜单打开时暂停实验、关闭移动与场景交互，但保留头显与手柄的实时跟踪。菜单在打开的位置保持世界朝向，重新打开时放置到玩家前方。手腕面板跟随手腕，交互提示跟随视角；告示板不受影响。

## 调整与维护

在 `Report VR Origin / ReportGameUI` 中调整配色、VR 菜单距离与尺度、手腕面板位置与旋转、HUD 显示以及保存选项。没有保存过的设置不会覆盖 Inspector 中的速度参数。

UI 在 Play 时生成，原生 uGUI 按钮和滑条同时供鼠标与 VR 射线使用。编辑器菜单 `Report VR / Install Game UI in All Levels` 用于安装绑定；`SetupReportUI.Validate` 检查 15 个场景的引用。

设置与已解锁关卡保存到本机 PlayerPrefs，前缀 `ChronoPivot.UI.`。保存已解锁关卡，不保存正在进行的物件位置或实验过程。

## 验证与预览

`ReportUIPlayCheck.Run` 用实际鼠标输入和虚拟 XR 手柄测试：菜单导航、提示不跳过实验、锁定关卡、音量滑条、暂停及恢复、VR 点击与滑条、重置和场景切换。

截图位于 `Documentation/UIPreviews`；通关截图由测试设置完成状态，用于检查界面展示，不作为玩家完成物理实验的记录。实际头显中的清晰度、面板舒适距离和串流延迟仍需设备检查。

原有抓取与实验测试会禁用 UI，以单独检查物理逻辑；UI 交互由上述检查覆盖。
