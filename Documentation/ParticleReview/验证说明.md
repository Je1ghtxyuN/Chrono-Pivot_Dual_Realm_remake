# 经典木船与粒子效果验证

- 第二关：模型射线检查确认坐板之间为敞开船舱；装载、卸载、超载回浮、桌面与大船同步、场地分离和重置检查通过。船体网格重新制作，浮力与载荷参数未改变。
- 第 2、11 关：空闲无水花；实际装卸产生水花；第 2 关两条船同步，在各自水面高度发射；真实水平位移产生少量尾水，竖直起伏不持续发射；重置/禁用清空。
- 第 6、10 关：沿用现有漏水粒子。按关阀、放入密封圈、实际入座、再开阀的顺序检查；关阀或密封后停止新水滴。
- 第 13 关真实运行：融化比例增加时出滴；同一观察时间内裸露冰出现 11 滴，罩住后未累积到第一滴，实际融化仍增加。拿离暖区、暂停、重置和禁用检查通过。
- 第 13 关碰撞：使用关卡原有雪球刚体与独立测试地面产生真实碰撞，雪粉短促发射；静止接触不持续出粉。`snow-impact-test.png` 是碰撞验证场景截图。
- 第 8、13 关使用同一融冰组件；四个修改关卡的配置前后物理组件序列化内容相同；重复配置不叠加粒子。新粒子每关总上限不超过 240，不使用粒子碰撞、灯光或阴影。
