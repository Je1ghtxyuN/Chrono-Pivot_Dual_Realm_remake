# NF4 真实文字测试记录

模型：Qwen2.5-3B-Instruct + 物理 LoRA；NF4 双重量化，BF16 计算；RTX 4060 Laptop 8 GB。

## 技术链路

29 项轻量测试、3 次真实 HTTP 中文问答、Unity 文字输入和回答显示通过；长上下文拒绝通过。中文输入测试使用 Unity 键盘事件，不包含操作系统 IME 或麦克风实测。

## buoyancy_hint_1

问题：为什么船装入配重后会下沉一点？

原始回答：先观察漂浮时浮力和重力关系，并确认“船仍漂浮，装入配重后吃水加深，水面高度基本不变”这一状态。

耗时：13.1 秒。

## buoyancy_followup_hint_2

问题：我发现船排开的水更多了，这与浮力和重力有什么关系？

原始回答：漂浮时浮力和重力平衡，同方向、等大小。吃水加深使排开水量增加，不能直接令浮力等于重力。

耗时：7.48 秒。

## newton_hint_3

问题：质量2 kg，水平合力6 N，我应该怎样检查加速度的计算？

原始回答：先观察合力和加速度的相对大小，并确认“惯性参考系，质量2 kg，水平合力6 N”这一状态。

耗时：6.96 秒。

## 样本质量：未通过

- 浮力追问把浮力和重力称为“同方向”，与竖直向上浮力、竖直向下重力相反的事实冲突。题设已静止漂浮时，两力大小相等；回答后半句也没有正确解释这一平衡。

- 三级提示只要求观察，未给出质量、合力、SI 单位、加速度方向与量纲的具体检查步骤。

- Unity 问答的 evidence_ids 为空，但当前界面显示所有检索卡片，其中有小角度单摆和全反射等无关卡片。引用与检索质量仍需后续改进。

本记录是少量样本人工检查，不是专家验收或统计评测。没有未量化对照，无法判断错误由量化、适配器或提示词中的哪项造成。
