## 两种操作方式

`Launch_VR.cmd` 正常初始化 OpenXR，连接 SteamVR。`Launch_Desktop.cmd` 使用 `Builds/WindowsDesktop` 的同内容副本和 `-desktop` 参数；桌面副本的 boot.config 移除了原生 XR 预初始化项，从而同时跳过原生和 C# 层的 XR 启动。每次 Windows 构建都会重新生成该副本。

无跟踪时自动选择桌面控制；头显有跟踪时，禁用键鼠移动、恢复头手姿态、VR 移动、重力与分段转向，避免两个驱动同时改变位置。

| 键鼠 | 行为 |
|---|---|
| 点击画面空白区域 | 锁定鼠标并进入操作；此首次点击不触发机关 |
| WASD | 按玩家朝向行走，1.6m/s，斜向不加速，保留地面和障碍碰撞 |
| 鼠标 | 水平转向、垂直观察，俯仰限制 ±80° |
| 左键 / E | 按住抓取屏幕中心4m内的道具，松开放下；机关抓住后拖鼠标 |
| 右键 / F | 拿住普通道具时按住蓄力，松开抛出；之后先松抓取键 |
| R | 关卡、模型、出生位置和视角重置 |
| Esc | 释放指针并停止移动/交互 |
| PgUp / PgDn | 通关后切换上一关/下一关；编辑器可开启调试导航 |

释放鼠标后可使用场景列表或 Reset 按钮。退出用窗口关闭按钮或 Alt+F4。场景切换后需要重新点击捕获鼠标。

## 验证

`DesktopPlayerCheck.Run` 使用真实 Play Mode 和虚拟 Keyboard / Mouse 事件验证移动、视角、交互、重置和切关。`OfflineVRCheck.Run` 回归验证 15 个关卡及头手跟踪、人物双手跟随、摇杆和握把等行为。`SetupCh46Player.Validate` 检查全部场景的人物绑定和碰撞隔离。

验证结果见 `Documentation/Verification`。虚拟输入不能替代真实 SteamVR 头显与串流测试。
