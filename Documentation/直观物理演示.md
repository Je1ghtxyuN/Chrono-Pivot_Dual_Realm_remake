# 直观物理演示

全部 15 个关卡采用“动手操作 → 观察变化”的展示方式。器材旁仅保留简短的操作与现象提示，当前步骤显示在空中；完成后显示出口已打开。菜单中仍可查看操作方法和一句话物理规律。

持续展示的重量、百分比、频率、角度误差、磁场、压力、功率、周期和公式已移除。材料用名称区分；方向用东南西北、目标用颜色标记、完成状态用灯光与模型变化表达。旋钮不再叠加数值刻度，摆长滑杆新增金色目标标记，太阳轨道新增方向标记。

- 浮力：加配重看船下沉，取出配重看船上浮；第二关大船继续同步。
- 声学：敲钟听余振消退，调节轮看振动增强，微调听声音趋于平稳。
- 地磁与光学：拨开司南看它回南，转镜看光束方向改变及接收器亮起。
- 电磁与液压：通电看衔铁吸合，压小活塞看另一端载荷抬升。
- 摆动与耦合：比较不同摆长的快慢，再让两条波形的节奏接近。
- 热、碰撞与结构：观察冰缩小与融水增加、骨牌连锁、雪球滚下以及下层支撑上层。

物理计算、器材碰撞、抓取方式、通关条件和判定阈值保留。数据展示的精简并不改变模拟规律。编辑器菜单 `Report VR / Presentation / Use intuitive physical demonstrations` 可重新应用展示配置；现有关卡生成流程会保留此配置。

当前复查版运行包位于 `Builds/Windows_LevelReview` 和 `Builds/WindowsDesktop_LevelReview`，包含后续木船、粒子、切关过渡、桥梁布局修正及无 BGM 状态。最初的展示检查报告与画面保留在 `Documentation/IntuitiveDemo`，后续结果见 `Documentation/ReasonabilityReview`。离线交互验证不代替真实头显手感验证。

首关及第二至第十四关的实际交互检查通过。第十五关此前的桥面板掉落问题已在后续合理性复查中重现并定位：备料抓取会撞掉已搭好的结构。扩大该处桌面、分开备料并增加中央搭建标记后，实际抓取、承重及等待和重置后的材料稳定检查通过。旧失败记录保留在 `IntuitiveDemo/garden-playtest.txt`，后续结果见 `ReasonabilityReview/garden-after.txt` 和 `关卡合理性复查.md`。
