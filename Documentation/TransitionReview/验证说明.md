# 切关粒子验证

- 用实际选关按钮触发切换：粒子发射、场景先淡出，随后加载，进入后淡入。
- 仿真暂停时过渡仍推进；非法/未解锁选择不触发；连续切换请求被拒绝。
- 到达后粒子和遮罩清空，菜单关闭，操作与正常时间恢复；跨场景只有一个持久特效组件。
- 完成任务的出口夹具后，玩家碰撞体实际进入出口触发器，触发同一套切关特效。
- 原有 UI 回归通过：鼠标菜单、锁定关卡、音量滑杆、暂停/恢复、虚拟 VR 手柄射线点击与滑杆、完成界面、重置确认、选关及桌面回退。
- 检查代表画面后，将粒子模拟和淡出同步，限制首次卡顿帧的视觉跳步；`departing.png` 显示淡出中的实际粒子，`arrived.png` 显示清理后的新场景。

此次改动接入统一加载入口，无需重写 15 个场景，也不改变实验物理与通关条件。界面测试使用独立的未解锁进度夹具，避免已有存档影响锁定关卡断言。

自动检查在隔离项目完成。虚拟 VR 操作不等于实物头显测试；头显帧率、立体显示和佩戴舒适度仍需设备验证。本次不重复各关卡完整实验流程，第 15 关此前记录的桥板问题未在此处理。
